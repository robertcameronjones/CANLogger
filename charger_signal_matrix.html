ISO-TP Frame Structure Reference
How multi-frame responses are assembled from raw CAN frames.
Frame Type Byte 0 Bytes 1–7 Description
Single Frame (SF) 0N payload (N bytes) N = payload length. Used by ODO response.
First Frame (FF) 1H LL first 6 payload bytes H/LL = total length (12-bit). Triggers Flow Control.
Consecutive Frame (CF) 2N next 7 payload bytes N = sequence number 1–F, wraps. CF1=21, CF2=22…
Flow Control (FC) 30 00 01 00 00 00 00 00 Continue To Send. BS=0 (no block limit), STmin=1ms.
